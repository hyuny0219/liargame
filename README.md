# 🎭 라이어게임 (Liar Game)

친구들과 온라인에서 실시간으로 즐기는 웹 기반 라이어게임입니다.

## 주요 기능

- **접속코드 로그인**: 회원가입 없이 사이트 접속코드 + 닉네임만으로 입장
- **공개방 / 비공개방**: 공개방은 로비 목록에 표시, 비공개방은 6자리 방 코드로만 입장
- **3가지 게임 모드**
  - **기본**: 라이어만 제시어를 모릅니다
  - **스파이 모드** (5인 이상): 제시어를 아는 스파이가 몰래 라이어를 돕습니다
  - **바보 모드**: 라이어 본인도 자신이 라이어인지 모른 채 다른 제시어를 받습니다
- **점수/라운드 시스템**: 여러 라운드 진행 후 최종 순위 발표
- **실시간 진행**: 설명 → 토론 → 투표 → 라이어 최종 추리 → 결과 (서버 기준 타이머)
- **내 차례 알림**: 설명 차례가 되면 화면 전체 알림 효과 + 진동(모바일)
- **토론 조기 종료**: 토론이 일찍 끝나면 방장이 바로 투표를 시작할 수 있음
- **12개 주제 카테고리 + 커스텀**: 음식, 동물, 직업, 장소, 스포츠, 영화/드라마, 물건, 나라/도시, 브랜드, 게임/만화, 자연, 탈것 (카테고리당 28개) + 방장이 직접 입력하는 커스텀 제시어
- **초대 링크**: `주소?room=코드` 링크 공유로 코드 입력 없이 바로 입장 (모바일 공유 시트 지원)
- **관전 모드**: 게임 중인 방에 입장하면 관전하다가 다음 라운드부터 자동 참여
- **강퇴**: 방장이 플레이어를 강퇴하면 해당 방에 재입장 불가
- **채팅 기록 복원**: 새로고침해도 최근 대화(100개)가 유지
- **효과음**: 내 차례·투표 시작·라운드 결과 알림음 (음소거 토글, 외부 파일 없는 합성음)
- **전적 표시**: 로비에서 내 라운드 승률·라이어 승률 확인 (서버 재시작 시 초기화)
- **링크 미리보기**: 카톡 등에 공유 시 제목/이미지 표시 (OG 태그), 홈 화면 추가용 아이콘 포함
- **재접속 지원**: 새로고침하거나 잠시 연결이 끊겨도 같은 자리로 복귀
- 방장 위임, 라이어 이탈 시 라운드 무효 처리 등 예외 상황 대응

## 게임 규칙

1. 시민들은 주제와 제시어를 받고, 라이어는 주제만 받습니다.
2. 정해진 순서대로 제시어를 한 문장씩 설명합니다. (라이어는 아는 척!)
3. 자유 토론 후 라이어로 의심되는 사람에게 투표합니다. (동표 시 1회 재투표)
4. 라이어가 지목되면, 라이어는 제시어를 맞혀 역전승할 수 있습니다.

**점수**
| 상황 | 점수 |
|---|---|
| 라이어 생존 (지목 안 됨) | 라이어 +3, 스파이 +2 |
| 라이어 지목됐지만 제시어 맞힘 | 라이어 +2, 스파이 +2 |
| 라이어(또는 스파이) 검거 | 시민 전원 +1, 정답에 투표한 시민 추가 +1 |

## 실행 방법

```bash
npm install
npm start
```

- 접속: http://localhost:3000
- 기본 접속코드: `1234`

**환경변수**

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 서버 포트 |
| `SITE_CODE` | `1234` | 사이트 접속코드 |

```bash
SITE_CODE=우리끼리비밀 PORT=8080 npm start
```

## 테스트

봇 3명이 방 생성 → 입장 → 한 라운드 전체(설명/토론/투표/추리/판정/결과)를 자동으로 플레이하는 E2E 테스트가 포함되어 있습니다.

```bash
npm test
```

## 배포 (Render 무료 티어)

1. 이 저장소를 GitHub에 푸시합니다.
2. [Render](https://render.com)에서 **New → Blueprint**를 선택하고 저장소를 연결하면 `render.yaml` 설정으로 자동 배포됩니다.
3. 배포 후 대시보드의 **Environment**에서 `SITE_CODE`를 원하는 접속코드로 변경하세요.

> 무료 티어는 15분간 요청이 없으면 잠들었다가 첫 접속 시 깨어납니다(수십 초 지연). 서버 메모리로 상태를 관리하므로 서버가 재시작되면 진행 중이던 방은 초기화됩니다.

Railway 등 다른 Node.js 호스팅에서도 `npm install` / `npm start`만으로 동작합니다.

## 추후 업데이트 (로드맵)

- **봇 플레이어**: 접속 인원이 3명 미만일 때 봇이 자동 투입되어 게임 진행
  - 제시어별 사전 작성 힌트로 설명, 무작위 투표/추리를 하는 규칙 기반 봇 (외부 API 불필요)
  - 대기실에서 방장이 봇을 수동 추가/제거하는 기능 포함 예정
  - 이후 Claude API 연동으로 자연스러운 설명을 하는 지능형 봇으로 업그레이드 검토
- **영구 전적/통계**: DB 도입 후 서버 재시작에도 유지되는 전적·순위표
- **채팅 도배 방지**: 전송 속도 제한

## 기술 스택

- **서버**: Node.js, Express, Socket.IO (게임 상태는 서버 메모리로 관리, DB 없음)
- **클라이언트**: 순수 HTML/CSS/JavaScript (빌드 도구 없음)
- 역할/제시어는 각 플레이어에게 개별 전송되어, 브라우저 개발자도구로도 다른 사람의 역할을 볼 수 없습니다.
